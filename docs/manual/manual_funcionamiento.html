1. Introducción y acceso

El sistema tiene dos caras: la app interna (con usuario) para operar el negocio, y un catálogo público de fotos para clientes interesados (sin login).

1.1 Ingreso

  1. Abra el navegador → dirección del sistema (ejemplo local: http://127.0.0.1:8000/login/).
  2. Escriba Usuario y Contraseña → Entrar.
  3. Verá el menú lateral y el área de trabajo. Abajo: sesión, Dashboard y Salir.
Si olvidó la clave, contacte al administrador. No comparta su usuario.

1.2 Roles (resumen operativo)

RolUso típico
Administrador / GerenciaTodo el sistema, usuarios, historial
VentasClientes, contratos, vendedores, seguimiento
CarteraPagos, cuotas, mora
ProyectosProyectos, polígonos, inventarios, mapas
ConsultaVer; edición limitada

Algunas acciones piden Confirmar acceso (volver a escribir la contraseña).

Regla de oro: Asesores de ventas ≠ Asesores alquiler. Son dos catálogos independientes.

3. Clientes

3.1 Alta

  1. Clientes → Nuevo cliente.
  2. Complete datos y documentos del expediente.
  3. Guarde → aparece en Listado de clientes.

3.2 Uso posterior

  • Como comprador en un contrato de venta.
  • Como inquilino en ficha de alquiler.
  • Como cliente reserva en un lote/casa apartado.
  • Reporte: Reporte PDF desde el listado.

4. Asesores de ventas (proyectos)

Para asesores de lotes y casas en venta, contratos y comisión de venta.

  1. Asesores de ventas → Nuevo asesor de ventas.
  2. Nombres, contacto, % comisión sugerido (sobre precio de venta), Activo.
  3. Opcional: vincular usuario del sistema.

4.1 Dónde se asigna

PreguntaRespuesta
¿Vendió una casa o lote?En el Contrato → campo Asesor de ventas
¿En el proyecto?No. El proyecto no lleva vendedor
¿Recibo de comisión de venta?Toma el asesor de ventas del contrato
Ruta: Gestión → Cartera y cobros → Contratos → crear/editar → elegir Asesor de ventas del catálogo.

5. Asesores de alquiler

Catálogo aparte para arrendamientos (locales y casas en alquiler).

  1. Asesores alquiler → Nuevo asesor.
  2. % sugerido sobre la renta mensual (no sobre precio de venta).

5.1 Dónde se asigna

Al preparar el Recibo de comisión de alquiler: campo Asesor del catálogo de alquiler (o nombre libre si no está registrado).

Ruta: Inmuebles → Alquileres → Comisión · local/casa… → elegir inmueble → seleccionar asesor.

6. Inmuebles: venta y alquiler

6.1 Venta

  1. Inmuebles → Venta.
  2. Casa: Nueva casa en venta / Casas nueva o usada.
  3. Lote: Nuevo lote o local / Lotes y locales.
  4. Opcional: Cliente reserva (apartado). Venta formal = Contrato.
  5. Suba fotos en la galería (alimentan el catálogo público si está Disponible).

6.2 Alquiler

  1. Inmuebles → Alquileres.
  2. Nuevo alquiler de local o de casa.
  3. Vincule Inquilino / arrendatario (módulo Clientes).
  4. Comisión: use el catálogo de Asesores alquiler.

7. Proyectos, polígonos y mapas

  1. Gestión → Proyectos y mapas → Proyectos → crear lotificación.
  2. Polígonos → etapas/agrupaciones.
  3. Registrar lotes en inventario de venta.
  4. Mapa interactivo (plano del proyecto) y/o Mapa catastral.

El proyecto organiza el inventario. El asesor de ventas se asigna después, por cada venta, en el contrato.

8. Contratos, pagos y mora

8.1 Contrato de venta

  1. Gestión → Contratos → Nuevo.
  2. Cliente + Inmueble + precio + plan de pagos.
  3. Campo Asesor de ventas (catálogo de Asesores de ventas).
  4. Desde el listado: Promesa PDF · Recibo asesor de ventas (comisión).

8.2 Pagos

  1. Gestión → Pagos.
  2. Registre prima, cuota o abono.
  3. Se puede emitir Recibo de ingreso del cliente (PDF).

8.3 Mora

Parámetros mora: reglas de mora de la cartera (según permisos).

10. Catálogo público de fotos

Muestra solo fotos de inmuebles Disponibles. Sin precios, contratos ni datos internos.

  1. App: Inmuebles → Catálogo para clientes.
  2. O URL: /catalogo/
  3. Botones Copiar enlace o WhatsApp.
  4. Puede compartir la galería de un inmueble concreto.
El cliente no necesita usuario. Suba las fotos desde la ficha del inmueble en la app.

11. Flujos de trabajo recomendados

11.1 Venta (camino completo)

  1. Cliente → Proyecto/polígono → Lote o casa en inventario.
  2. Contrato + Asesor de ventas.
  3. Promesa PDF → Pagos → Recibo ingreso cliente.
  4. Recibo de comisión al asesor de ventas.

11.2 Alquiler

  1. Cliente (inquilino) → Ficha Alquileres + vínculo.
  2. Asesor alquiler (si no existe).
  3. Recibo de comisión de alquiler con asesor del catálogo.

11.3 Compartir fotos

  1. Fotos en la app · estado Disponible.
  2. Catálogo para clientes → copiar / WhatsApp.

14. Preguntas frecuentes y problemas comunes

No veo Asesores de ventas ni Asesores alquiler

Su rol no tiene permiso. Pida a Admin/Gerencia/Ventas que le habiliten la gestión de asesores.

¿Dónde asigno quién vendió una casa?

En el Contrato, campo Asesor de ventas. No en el proyecto.

¿Dónde asigno quién intermediaron un alquiler?

En el Recibo de comisión de alquiler, campo Asesor del catálogo de alquiler.

¿Puedo usar el mismo nombre en venta y alquiler?

Sí, pero hay que darlo de alta en ambos catálogos (o escribir nombre libre solo en el recibo de alquiler). El sistema no los mezcla solo.

El catálogo público no muestra un inmueble

Proyecto activo + estado Disponible + fotos cargadas.

Usuario o contraseña incorrectos

La clave no coincide con la de la base. El administrador debe restablecerla. No es un error del formulario.

Pide confirmar acceso otra vez

Es normal en operaciones sensibles. Use Confirmar acceso e ingrese su contraseña.
