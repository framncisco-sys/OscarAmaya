Configuración técnica del servidor (solo referencia)

El envío SMTP se define en el archivo .env del proyecto (puede partir de .env.example). Hacen falta al menos EMAIL_HOST, EMAIL_HOST_USER y EMAIL_HOST_PASSWORD. Sin esa configuración, el sistema solo registrará intentos en consola del servidor.

Probar SMTP en la PC donde corre la aplicación (PowerShell o CMD, carpeta del proyecto): 

python manage.py probar_correo su@correo.com

El comando muestra la configuración detectada y envía un correo de prueba. Si falla: contraseña de aplicación (p. ej. Gmail), puerto 587 con TLS o 465 con SSL, y que el remitente coincida con la cuenta si el proveedor lo exige.
